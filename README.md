The game is a hybrid approach to the genre; namely blending factory-automation style with tower defense. The game allows the player not only to defend, but also attack - warfare is concentraded on the fixed, randomly generated paths for units to follow. The player must secure the production of various resources which allows army recruitment and production of ammunition for defense towers.

## Installation

Simply download the latest Tvorin build. Unpack the zip file and run tvorin.exe.
